# Rhino Cyberspace

Standalone ESP32 firmware client for [cyberspace.online](https://cyberspace.online),
a retro text-only social network. Milestone 1 is cIRC chat on the Elecrow
ThinkNode M9, with a web config page served by the device. No phone app or
companion is needed.
