# Rhino Cyberspace

Standalone ESP32 firmware client for [cyberspace.online](https://cyberspace.online),
a retro text-only social network. It runs on the Elecrow ThinkNode M9 and
offers cIRC chat (milestone 1), C-Mail private messages (milestone 2), and a
web config page served by the device. No phone app or companion is needed.

- [Using it](docs/USE.md): setup, buttons, rooms, C-Mail, web config
- [Building](docs/BUILD.md)
- [Testing](docs/TESTING.md): unit tests, the fake-API build, and the live checklist

## Time zone data

The automatic time zone uses zone boundaries bundled in the firmware
(`src/tz/tz_data.h`, generated by `scripts/tzgen.py`; see
[Building](docs/BUILD.md#time-zone-data)).

Time zone boundaries © OpenStreetMap contributors (ODbL), from timezone-boundary-builder.
