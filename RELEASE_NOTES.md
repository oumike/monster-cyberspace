### Monster for Cyberspace (next release)

### New

- **bmorcelli's Launcher**: Monster can be installed through [Launcher](https://github.com/bmorcelli/Launcher) on the boards it supports: ThinkNode M9, Wio Tracker L2, T-Deck Plus, CrowPanel Advance 5.0", T-LoRa Pager, T-Deck Pro, Cardputer ADV, T-Display P4 and Tab5. Install the `-ota.bin` for your board from Launcher (on the Cardputer ADV, the new `-app.bin`). Under Launcher, updates come through Launcher instead of over the air, and Fluffy is the default one (a custom mascot needs the browser flasher's install). See "Installing through Launcher" in the user guide.

### Changes

- Cardputer ADV: releases now include `monster-cyberspace-cardputer-adv-vX.Y.Z-app.bin`, the app alone, for Launcher. The browser flasher still uses the full image.
- Installs from the browser flasher behave as before.
